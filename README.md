# Bani

Convert and lightly edit media files entirely in your browser. Nothing is uploaded.

Video is supported today (powered by [Mediabunny](https://mediabunny.dev)); audio, image, PDF and text are on the way. See [ROADMAP.md](./ROADMAP.md).
